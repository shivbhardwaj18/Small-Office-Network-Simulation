# 📌 Project Overview

The **Small Office Network Project** is a practical networking simulation designed using **Cisco Packet Tracer**.

This project demonstrates how different departments inside an office can communicate through properly configured routers, switches, and end devices.

The network consists of four major departments:

* 🖥️ Server Room
* 👨‍💼 Chairman Room
* 💻 IT Department
* 🧑‍💻 Computer Department

The project helps learners understand:

* Network topology design
* IP addressing
* Static routing
* Router configuration
* Switch configuration
* End device communication
* Packet transmission between networks

# 🔧 Configuration Steps

# 🖥️ Configure End Devices (PCs)

### Assign IP Address

1. Click on the PC
2. Open the **Desktop** tab
3. Select **IP Configuration**
4. Enter:

   * IP Address
   * Subnet Mask
   * Default Gateway

---

# 🔀 Configure Router

### Router Setup Steps

1. Click on the router
2. Configure router interfaces
3. Assign IP addresses
4. Enable interfaces
5. Configure static routing

---

# 📡 Static Routing

Configure static routes to allow communication between different departmental networks.

Example:

```bash id="94xan7"
ip route [destination-network] [subnet-mask] [next-hop]
```
